# 條件式知識應放進 references，避免每次都載入

API 文件、業務規則與長篇背景資料，如果只在特定任務中才會用到，就適合放進 `references/`。<br>
`SKILL.md` 要清楚指出何時讀取哪份 reference，否則檔案不會因為放在資料夾裡就自動載入。
