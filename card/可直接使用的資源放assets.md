# 可直接套用的模板與資源應放進 assets

`assets/` 存放的是產出時能直接複製、填寫或使用的模板、圖片與輸出骨架。<br>
它和 `references/` 的差別在用途：reference 幫助 Agent 理解與判斷，asset 則直接成為產出的一部分。
