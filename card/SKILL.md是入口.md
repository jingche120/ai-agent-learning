# SKILL.md 是 Skill 的入口，不是整個 Skill

一個 Skill 的本體是整個資料夾，`SKILL.md` 只是 Agent 進入這個 Skill 時必讀的核心指令。<br>
只有 `SKILL.md` 也能構成完整 Skill；`references/`、`scripts/` 與 `assets/` 都是有需要才加入的輔助結構。
