# Script 放進 Skill 後不會自動執行

`scripts/` 只負責存放程式，不會自行決定何時運行。<br>
`SKILL.md` 必須說明觸發時機、必要輸入與驗證方式，Agent 才知道如何把 script 納入完整流程。
